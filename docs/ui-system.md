# UI System

The visual system uses ClassPulse green as the primary semantic action color, muted blue for neutral analytics, amber for warnings, and red for risk. Shared primitives live in `src/components/ui` and use semantic class names backed by the existing token stylesheet plus Tailwind v4.

Status badges include text and a dot, so meaning is not communicated by color alone. Tables remain horizontally scrollable on narrow screens. Focus rings are preserved for keyboard users.
